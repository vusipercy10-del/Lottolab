# LottoLab Master Prompt Library

## 1. Master analysis
Analyze the selected lottery using the full LottoLab Master System. Calculate frequency, recent frequency, prime, square, cube, triangular, Fibonacci, twin-prime, multiples, multiple-overlap, last digits, 3/4/5-ending patterns, duplicate endings, ending transitions, odd/even, low/high, zones, pairs, triplets, repeats, gaps and draw-to-draw transitions. Build Master, Core, Alternative and Reserve pools. Score and backtest the resulting combinations. Clearly separate historical observation from inference.

## 2. Multiple overlap
Find the numbers with the greatest overlap across ×2–×10. Rank them, compare them with frequency and last-digit structure, and build a multiple-overlap pool.

## 3. Last-digit transition
Compare each draw with the previous draw. Count retained endings, disappearing endings, new endings, exact pattern repeats, 2-ending retention, 3-ending retention and 4-ending retention. Build a transition table.

## 4. Ending wheel
Find the strongest 3-ending and 4-ending combinations over the selected history. Create a 10-line ending wheel and test it with walk-forward backtesting.

## 5. Pool overlap
Create Primary, Alternative and Reserve pools. Identify the intersection and rotation numbers. Build combinations using different Core/Rotation proportions and test them historically.

## 6. 3/15
Use the full Master System for 3/15. Generate an 8-number strong pool, 6-number core pool, 4-number primary pool, alternatives and reserve combinations. Check prime balance, multiple overlap, last digits and backtest.

## 7. 4/20
Analyze both fields where applicable. Separate field-level patterns and then test combined ticket structures.

## 8. 7/49
Use 100/50/20/12/10 windows. Compare long-term and recent structure, then create a Master 12-number pool and balanced 7-number candidates.

## 9. 20/80 Keno
Analyze zones, endings, multiples, mathematical types, pairs, triplets, repeats and transitions. Build a broad Master Pool and smaller candidate pools.

## 10. Backtest
Run a walk-forward test: for each historical target draw, train only on draws before it, generate the candidate pool/tickets, and compare with the target draw. Report average matches, maximum matches, hit distribution and baseline comparison.

# LottoLab Ultimate Multi-Strategy Master Prompt

Use the Ultimate Master Prompt from the **Master Engine** dashboard. It runs the full staged workflow: Data Validation → Historical Analysis → Markov → Zones → Sections → Pair/Triplet → Cluster/Macro → Root/Ending → Delta → Balance → Combinatorial/Wheel → Filters → Consensus → Backtesting → Final Ranking.

The dashboard adapts the number range, pick count, zone count and section count to the selected game. It separates historical observation, statistical signal, model output and backtested performance and never presents a guaranteed outcome.
